# Fotos de la experiencia

La portada usa todas las fotos de `Fotos Daiara Bebe/` para formar el collage superior.

Las cartas usan las fotos de `Fotos Nosotros Juntos/` en pares de dos imágenes por carta. Si agregás o reemplazás fotos, actualizá las rutas del arreglo `letters` en `index.html`.

Las fotos verticales funcionan porque la página las recorta sin deformarlas mediante `object-fit: cover`. Si una foto no carga, queda visible el fallback cálido de la carta.
